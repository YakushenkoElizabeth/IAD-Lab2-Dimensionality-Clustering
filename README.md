# Лабораторна робота № 2

**Дисципліна:** Інтелектуальний аналіз даних

**Тема:** Зменшення розмірності даних, кластеризація та класифікація текстів

## Мета роботи

Ознайомитися з методами зменшення розмірності даних, кластеризації та класифікації текстової інформації, навчитися застосовувати алгоритми машинного навчання, візуалізувати результати та оцінювати якість моделей за допомогою відповідних метрик.

## Завдання роботи

1. Застосувати метод головних компонент (PCA) для зменшення розмірності даних про кіберзагрози, порівняти якість класифікації до та після перетворення, а також виконати візуалізацію даних за допомогою t-SNE.
2. Виконати кластеризацію даних методом K-Means, визначити оптимальну кількість кластерів за допомогою методу ліктя та коефіцієнта силуету, візуалізувати результати й порівняти отримані кластери зі справжніми класами.
3. Виконати класифікацію SMS-повідомлень, провести попередню обробку текстів, побудувати хмари слів, застосувати TF-IDF для перетворення тексту на числові ознаки, навчити класифікатор та оцінити його якість.

## Використані технології

- Python
- Google Colab
- Pandas, NumPy
- Matplotlib, Seaborn, WordCloud
- Scikit-learn

## Методи та алгоритми

- PCA (Principal Component Analysis)
- t-SNE (t-distributed Stochastic Neighbor Embedding)
- K-Means
- TF-IDF (Term Frequency-Inverse Document Frequency)
- Random Forest
- Multinomial Naive Bayes

## Результати роботи

У ході лабораторної роботи досліджено методи зменшення розмірності, кластеризації та класифікації текстових даних. Виконано порівняння якості класифікатора Random Forest до та після застосування PCA, візуалізацію даних за допомогою t-SNE, кластеризацію мережевих сесій методом K-Means та класифікацію SMS-повідомлень за допомогою TF-IDF і Multinomial Naive Bayes. Результати оцінено за допомогою метрик Accuracy, Precision, Recall, F1-score, Silhouette Score та Adjusted Rand Index (ARI).
